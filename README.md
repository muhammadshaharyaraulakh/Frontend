# Mizan AI — Frontend

React + Tailwind + shadcn/ui dashboard for Pakistan Court Judgment Research.

## Tech Stack
- React 19 / Vite
- Tailwind CSS v4
- shadcn/ui
- Axios

## Features
- Judgment Search Dashboard
- Case Treatment Tracker
- Research Memo Viewer
- Compare Tool (up to 4 judgments)
- Alerts & Monitoring

## Setup
git clone https://github.com/yourusername/pakistan-legal-frontend
cd pakistan-legal-frontend
npm install
cp .env.example .env

## Run
npm run dev
